# Sistem Manajemen Perpustakaan Kampus
Perpustaan adalah salah satu tempat yang menyediakan berbagai macam koleksi buku untuk mendukung kegiatan pembelajaran mahasiswa. Dalam pengelolaannya, perpustakaan perlu mengatur kleksi buku, proses peminjaman, dan lokasi penyimpanan. Jika data tersebut tidak dikelola dengan baik, proses pencarian buku, pencatatan peminjaman, dan pengelolaan buku dapat menjadi kurang efektif.
Berdasarkan permasalahan yang ada dibuatlah program sistem manajemen perpustakaan kampus menggunakan pemrograman bebasis Java. Program ini dibuat untuk membantu memudahkan dalam pengelolaan data perpustakaan yang dapat digunakan oleh pengguna.
